# Design decisions

| Date | Decision | Basis | Revisiting condition |
|---|---|---|---|
| 2026-10-23 | Treat project as 700 W H100-*class* jet-cooling research, not an H100-qualified product | No verified complete H100 package/heat map data | OEM geometry and operating limits obtained |
| 2026-10-23 | Choose OpenFOAM Foundation v14 as initial CFD distribution | Official Ubuntu install and current Foundation release | Toolchain incompatibility or validated alternative |
| 2026-10-23 | Do not create a nominally runnable full CFD model with guessed manifold geometry | No-assumptions rule | All inputs sourced or explicitly designated justified design choices |
| 2026-10-23 | Recommend private GitHub repository initially | IP/confidentiality and team-review considerations | Project supervisor authorizes publication |
